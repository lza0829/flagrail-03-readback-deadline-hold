# 灰度轨

中文名：**灰度轨** · 前缀 `flagrail` · 端口 **6800 / 11800**

## 骨架

**开关版本入轨 → 分桶灰度下发 → 回读确认 → 失效/回滚互证**

皮：功能开关 / 配置灰度控制台。去皮是 **版本入轨 + 分桶下发 + 回读确认 + 命运互证**，不是配置 CRUD、不是 RBAC、不是发版审批闸。

## 已落地：回读截止收口

下发即约定回读截止（`下发票.回读截止`，默认站规 `回读截止秒`），边缘名册随票。
**截止扫描必须改票态或显式延期**，禁止假已下发可升：

- 无书面延期 → **以超时收口为准**：`POST /api/截止扫描` 把过期票打进「超时收口」，
  晋升拒绝，迟到确认不得把票拉回可升（`POST /api/回读` 写入侧同样失败闭）。
- 有书面延期且未耗尽 → **以书面延期为准**：`POST /api/回读延期` 落延期实体
  （`回读延期` 表，站规 `最大延期次数` 封顶），票保持已下发待确认，
  有效截止物化为延期截止；延期耗尽才收口；原截止瞬间不得直接当可升。
- 可区分点：过原截止、延期未耗尽时，晋升拒绝且票态**不是**超时收口。

硬约束：截止扫描、回读写入、命运条同票同事务（`BEGIN IMMEDIATE` 写事务）；
扫描与迟到确认并发失败闭；扫描整体原子不得半截。
核证 `GET /api/截止核证?票号=` 返回 截止、延期截止、票态、可否晋升、valid；
晋升闸 `POST /api/晋升` 要求 已下发 + 未过有效截止 + 边缘名册齐套。
贯验点名：假已下发可升 / 收口无命运 / 晋升无命运 / 悬空延期。

夹具：`回读截止样例`（两边缘一确认→拨截止→甲收口·乙延期）、
`回读迟到样例`（迟到确认：甲拒不可复活·乙计入延期窗口）。
测试：`cd backend && pip install pytest httpx && python -m pytest tests/`
（双夹具 + 并发失败闭 + 贯验协同，5 项）。
